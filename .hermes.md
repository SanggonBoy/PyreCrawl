# PyreCrawl — Project Rules

## Repo hygiene (KRITIS — repo ini public)

**JANGAN PERNAH membuat file/folder baru di root repo atau di `src/` yang bukan bagian dari package.**

- Hermes DAN agent lain (Codex/Claude) yang bekerja di repo ini wajib menjaga working tree bersih.
- Dilarang: `.hermes-tmp.*`, `*.tmp`, `*.bak`, file log, folder scratch, file pribadi, notes, reminder, dump debug.
- Semua file sementara WAJIB ditaruh di `$TEMP` (mis. `C:/Users/<user>/AppData/Local/Temp/`), BUKAN di dalam repo.
- `__pycache__/`, `*.pyc`, `*.egg-info/`, `build/`, `dist/`, `.pytest_cache/` = sudah di `.gitignore`, tapi tetap **jangan membuatnya di working tree** — gunakan `--no-cache` bila perlu, atau biarkan di `dist/` (di-ignore).
- Kalau tidak sengaja terlanjur membuat file sampah: **hapus segera** sebelum mengakhiri sesi.
- **Jangan commit** file sampah. Sebelum `git commit`, ALWAYS cek `git status --short` — kalau ada file yang tidak dikenal, hapus dulu atau tambah ke `.gitignore`.

## Workflow

- Simpan file build di `dist/` (already gitignored).
- Kalau perlu file venv baru, gunakan `${TEMP}/pyrecrawl-*` bukan di repo.
- Jangan pernah menimpa `.venv` lama tanpa alasan; gunakan path temp untuk test.
- Untuk verifikasi install: buat venv temp di `$LOCALAPPDATA/Temp/` lalu hapus.

## Secrets / PII

- Dilarang commit API keys, token, password, atau path personal (mis. `C:\Users\nunun`) ke repo.
- Semua config yang memuat secrets disimpan di `.env` yang di-ignore.

## Git hygiene

- Commit message jelas, satu perubahan per commit.
- Jangan force-push ke `main` tanpa izin user.
- Jangan pernah mengubah `LICENSE` atau metadata author tanpa izin user.
